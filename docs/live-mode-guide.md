# 现场模式(LiveSlide)使用说明 —— 给 Viho

开课时在会场投影上给全场看本批的成绩:平均总分、五维平均、档位分布、最弱维度分布,一共四屏。
**它不会自动翻页**,只有你按键或点按钮才会换屏。学员写的开放题原文不会出现在任何一屏上。

## 课前(建议开课前 15 分钟,接好投影之后)

1. 用接投影的那台电脑,浏览器打开 **https://compass.qiai.tech/admin**,用管理员邮箱登录(邮件里的链接要在**同一个浏览器**里点开)。
2. 点上方的 **「现场模式」**。
3. 左上角的下拉框选**这一场的批次**(默认是「全部批次(不含测试)」)。
   选完之后**在页面空白处点一下**,让光标离开下拉框 —— 光标停在下拉框里时,方向键和 + / − 会去改下拉框,而不是改投影。
4. 点 **「全屏投影」**。投出去的只有那一块画面:浏览器地址栏、后台菜单、上面那排按钮都不会出现在投影上。
5. **调字号**:翻到第 2 屏(五维平均 —— 四屏里字最小的一屏),走到最后一排看一眼,看不清就按 **+**,直到看得清。

## 讲课时的按键

| 按键 | 作用 |
|---|---|
| **→** / **←** | 下一屏 / 上一屏 |
| **+**(或不按 Shift 的 **=** 键) | 整屏放大 10%,最大 150% |
| **−** | 整屏缩小 10%,最小 70% |
| **0** | 回到 100% |
| **Esc** | 退出全屏(浏览器自带) |

- 按 + / − / 0 之后,画面**右下角会显示当前比例(比如「120%」),两秒后自动消失**。到 150% 再按 + 仍会显示「150%」,表示已经到顶。
- **比例会记在这台电脑的这个浏览器里**,刷新页面、关掉再开都保持。换一台电脑或换一个浏览器,会从 100% 开始。
- 只改投影这一块的大小,**不影响学员看到的任何页面**,也不影响后台其他页面。
- 按住 **Cmd / Ctrl** 再按 + / − 是浏览器自己的整页缩放,和这里无关;不需要用它。

## 万一

- **按 + 没反应**:光标多半还停在批次下拉框里 —— 在画面上点一下再按。
- **点了「全屏投影」没有全屏**:浏览器拒绝了(少数情况),现场模式那一块会变成一行错误说明。**刷新页面**(字号比例不会丢),重新点「现场模式」、重新选批次,再点「全屏投影」。
  实在不行再用浏览器自己的全屏(Mac 上的 Chrome:Ctrl + Cmd + F)—— 但那样投出去的是**整个页面**,上面那排按钮和后台菜单也会出现在投影上。
- **画面上方出现黑底白字「演示数据」**:你选到了测试批次,换回这一场的批次。

## 已经知道的

- 在 1024×768、1280×720、1280×800、1920×1080 四种常见投影分辨率下,70%–150% 之间都放得下,不会有字被挤出屏幕或被截断。
  唯一的情况:批次名很长(30 个字左右)、又放到 150%、又是 4:3 的老投影时,左上角的批次名会折成两行 —— 不影响阅读。
- 字最小的是第 2 屏雷达图上的维度名和分数。100% 时在 1024×768 上约 13 像素,放到 150% 约 19 像素。
- 后排到底看不看得清,只有在会场才知道 —— 这正是 + / − 存在的原因。
