# 后台密码登录 —— 给 Viho

2026-10-14 起,后台登录页默认是「邮箱 + 密码」。邮件链接还在,作为备用入口。
**没有单独的「忘记密码」页面**:忘了密码,就用邮件链接登录,进后台之后在「设置密码」里改。

## 第一次:设置密码(只做一次)

你的账号是用邮件链接建的,一开始**没有可用的密码**,所以第一次必须走邮件链接。

1. 浏览器打开 **https://compass.qiai.tech/admin**。
2. 点登录框下面的 **「忘了密码或还没设置过?用邮件链接登录」**。
3. 输入你的管理员邮箱,点「发送登录链接」。
4. 打开邮件里的链接 —— **要在同一个浏览器里打开**(在手机上点开电脑上申请的邮件会失败)。
5. 进了后台之后,点右上角的 **「设置密码」**。
6. 「新密码」和「再输入一次」都填同一个密码,**至少 12 个字符**,点 **「保存密码」**。
   看到「密码已保存」就好了。浏览器问要不要记住密码,可以点记住。
7. (建议)点「退出」,再按下面「以后」那一节用密码登录一次,确认能进 —— 然后把结果告诉我们。

如果第 6 步提示「为了安全,改密码需要最近登录过」:点「退出」,从第 2 步重新走一次邮件链接登录,马上再设置。
(这是 Supabase 的「Secure password change」开关:登录超过 24 小时就要求重新登录才能改密码。)

## 以后:用密码登录

1. 打开 **https://compass.qiai.tech/admin**。
2. 填邮箱和密码,点 **「登录」**。不用等邮件,也不限于同一个浏览器。

登录不进去时,页面只会说一句「没能登录:邮箱或密码可能不对,或者这个邮箱还没设置过密码……」——
**它故意不说是邮箱错还是密码错**(否则这个页面就成了「某个邮箱是不是管理员」的查询器)。
这时用邮件链接登录,进后台后在「设置密码」里重新设一个。连续失败几次之后要等几分钟再试。

## 忘了密码 / 想换密码

- 忘了:登录页点「用邮件链接登录」→ 收信、在同一个浏览器打开 → 进后台 → 「设置密码」。
- 想换:登录状态下直接点「设置密码」。

## 不会变的

- **谁能进后台,仍然只由允许名单决定**。不在名单里的账号,不管用密码还是邮件链接登录,都会看到「这个账号不在后台允许名单里」。
- 学员那一边完全不受影响:学员不登录后台,也不用密码。
